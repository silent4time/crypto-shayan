# CryptoPay WooCommerce — Security-Hardened Fork

فورک مستقل و غیررسمی از افزونه‌ی [CryptoPay WooCommerce](https://cryptopay-woocommerce.beycanpress.com/) (ناشر اصلی: BeycanPress)، بر پایه‌ی نسخه‌ی رسمی **2.4.5**.

این مخزن **محصول رسمی BeycanPress نیست**؛ صرفاً یک بازبینی امنیتی مستقل روی نسخه‌ی رایگان (Lite) این افزونه است. هیچ قابلیتی از نسخه‌ی پولی (Full/Pro) در این مخزن اضافه نشده است.

## نسخه فعلی

`2.4.5-security.1` — جزئیات کامل در [CHANGELOG.md](./CHANGELOG.md)

## چه چیزی تغییر کرده؟

خلاصه (برای جزئیات کامل به CHANGELOG مراجعه کنید):

- بستن دسترسی عمومی REST API (بررسی مالکیت سفارش)
- حذف `serialize()`/`unserialize()` به نفع JSON
- اعتبارسنجی دقیق‌تر آدرس کیف‌پول (regex به‌جای طول رشته)
- افزودن Rate limiting ساده روی endpointهای عمومی

## نصب

1. از [Releases](../../releases) آخرین نسخه‌ی zip را دانلود کنید.
2. در پیشخوان وردپرس: افزونه‌ها ← افزودن ← بارگذاری افزونه.
3. فایل zip را انتخاب و نصب/فعال کنید.
4. اگر افزونه‌ی اصلی BeycanPress از قبل نصب است، ابتدا آن را غیرفعال/حذف کنید تا تداخل پیش نیاید.

## پیش از استفاده در سایت اصلی

حتماً روی یک محیط staging یک خرید تستی — هم با کاربر لاگین‌شده و هم به‌صورت مهمان — انجام دهید. جزئیات در بخش «نکات ارتقا»ی CHANGELOG.
