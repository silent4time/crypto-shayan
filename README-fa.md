# CryptoPay WooCommerce — فورک امنیتی

فورک مستقل و غیررسمی از افزونه‌ی [CryptoPay WooCommerce](https://cryptopay-woocommerce.beycanpress.com/) (ناشر اصلی: BeycanPress)، بر پایه‌ی نسخه‌ی رسمی **2.4.5**.

این مخزن **محصول رسمی BeycanPress نیست**؛ صرفاً یک بازبینی امنیتی مستقل روی نسخه‌ی رایگان (Lite) این افزونه است. هیچ قابلیتی از نسخه‌ی پولی (Full/Pro) اضافه نشده است.

## نسخه فعلی

`2.4.5-security.3` — جزئیات کامل در [CHANGELOG.md](./CHANGELOG.md)

## چه چیزی تغییر کرده؟

خلاصه (برای جزئیات کامل به CHANGELOG مراجعه کنید):

- بررسی خودکار آپدیت و «Update now» یک‌کلیکی از روی Releases همین مخزن گیت‌هاب
- بستن دسترسی عمومی REST API (بررسی مالکیت سفارش)
- حذف `serialize()`/`unserialize()` به نفع JSON
- اعتبارسنجی دقیق‌تر آدرس کیف‌پول (regex به‌جای طول رشته)
- افزودن Rate limiting ساده روی endpointهای عمومی

## روش انتشار یک آپدیت جدید (برای فعال‌ماندن آپدیت خودکار)

۱. نسخه را در `index.php` و `app/Loader.php` ببر بالا.
۲. کامیت کن، یک تگ بساز (`vX.Y.Z-security.N`) و push کن.
۳. از همان تگ یک **Release** در گیت‌هاب بساز و فایل zip نصب را به‌عنوان asset پیوست کن.

سایت‌هایی که این افزونه را دارند، خودکار متوجه‌ی آپدیت می‌شوند.

## نصب

فایل `cryptopay-woocommerce-v2.4.5-security.3.zip` را مستقیماً از پیشخوان وردپرس (افزونه‌ها ← افزودن ← بارگذاری افزونه) نصب کنید. اگر نسخه‌ی رسمی BeycanPress از قبل نصب است، ابتدا آن را غیرفعال/حذف کنید.

## پیش از استفاده در سایت اصلی

حتماً روی یک محیط staging یک خرید تستی — هم با کاربر لاگین‌شده و هم مهمان — انجام دهید. جزئیات در بخش «نکات ارتقا»ی CHANGELOG.
